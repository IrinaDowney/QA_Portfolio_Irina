## 🧪 Testing Types Covered

| Testing Type | Description |
|---|---|
| Functional | Core features work as expected |
| Positive | Valid inputs produce correct results |
| Negative | Invalid inputs handled gracefully |
| Boundary | Edge values tested at min/max limits |
| Equivalence Partitioning | Input groups validated efficiently |
| Cross Browser | Chrome, Firefox, Safari |
| Cross OS | Windows 10, MacOS |
| ADHOC | Exploratory unscripted testing |
